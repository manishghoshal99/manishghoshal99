# Credits

Everything on the profile page is drawn by my own scripts, apart from the things below.

## Type

- **TeX Gyre Heros** (regular and bold), by GUST e-foundry, under the [GUST Font License](licenses/GUST-FONT-LICENSE.txt). The titles and labels on the plates, and the text on the pond page.
- **Fragment Mono**, by the [Fragment Mono project authors](https://github.com/weiweihuanghuang/fragment-mono), under the [SIL Open Font License](licenses/OFL-FragmentMono.txt). The captions.

GitHub does not let README images load fonts, so the plates set their type as vector paths made from these fonts' outlines. The pond page uses subsets of the same fonts as ordinary web fonts.

## The koi

- The vector koi is drawn from scratch in code, on the plates and on the pond page.
- The small pixel specimen in the pond log is drawn every night by [git-koi](https://github.com/yalongwastaken/git-koi) by Anthony Yalong (MIT), from my public GitHub activity.

## The pond page

- Buttons, switches, tooltips and key hints are [Astryx](https://github.com/meta/astryx) components (Meta, MIT), re-coloured to the plate palette.
- Built with React and Vite.

## Counting

- Profile visits: [komarev.com/ghpvc](https://github.com/antonkomarev/github-profile-views-counter), a view counter loaded as a 1 by 1 image at the foot of the README.
- Pellets and waves: a small function of my own on Vercel, with a small Redis store from Upstash. A feed or a wave adds one to a count and notes the time; the function keeps nothing about a visitor.

GitHub's image proxy fetches the badge and the pond picture, so neither komarev nor the function sees the visitor for those. Opening the pond page, feeding or waving there, and a click on Feed or Wave in the README reach the function from the visitor's browser. It reads a few request headers, to tell a click from a machine and to refuse other sites, and keeps none of them. Vercel, which hosts the function, keeps its own request logs, as any web host does. The pond page sends no identifiers.

## Weather

- The weather on the live pond comes from Open-Meteo: [Weather data by Open-Meteo.com](https://open-meteo.com/), under CC BY 4.0. Only a look and a whole temperature are kept from each answer.

## Inspiration

The plate layout (a hairline grid, a title cell, two small facts, artwork laid over the grid at a slight angle, a caption that reads like a prompt) is an homage to the poster studies at [filatov.design](https://www.filatov.design), and "Koi-studies" answers "Apple-studies" in particular. All artwork here is original and generated by code; no image model was used.
